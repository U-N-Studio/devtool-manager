# ui 模块 — 设计

## 布局

```
┌─────────────────────────────────────────┐
│ [Environment]  [Packages]               │  ← 标签栏
├─────────────────────────────────────────┤
│ 工具栏: 筛选器 + 操作按钮 + 消息       │
├─────────────────────────────────────────┤
│ 工具信息卡 (条件显示)                   │
├─────────────────────────────────────────┤
│ 可滚动列表                              │
├─────────────────────────────────────────┤
│ 分页导航                                │
└─────────────────────────────────────────┘
```

## 配色

| 元素 | 颜色 | 用途 |
|------|------|------|
| --bg | #1a1a2e | 背景 |
| --surface | #16213e | 表面/卡片 |
| --accent | #4fc3f7 | 功能tag/选中态 |
| --accent2 | #81c784 | 语言tag |
| --danger | #ef5350 | 删除按钮 |
| --warn | #ffa726 | 未安装tag |
| --success | #66bb6a | 已安装tag/添加按钮 |
| --text | #e0e0e0 | 主文字 |
| --text-dim | #888 | 次要文字 |

## 组件

### 标签栏
- 两个 button，active 态底部 2px 蓝色边框

### 工具栏
- flex 布局，label + select + button + msg
- select 暗色背景圆角

### 环境行
- `.env-row`: [name 180px] [source badge] [value flex-1] [Edit] [Del]

### 包行
- `.pkg-row`: [func-tag] [lang-tag] [install-tag] [name] [version auto] [Add|Del]
- tag: 10px 字号，圆角3px，半透明背景

### 分页
- 居中，Prev/Next 按钮 + "1-50 / 205" 信息

### 对话框
- 使用原生 prompt()/confirm()（简洁，无需自定义组件）
