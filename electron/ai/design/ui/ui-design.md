# DevTool Manager — UI 设计

## 布局

```
┌─────────────────────────────────────────┐
│ [Environment]  [Packages]               │  ← 标签栏
├─────────────────────────────────────────┤
│ 工具栏: 筛选器 + 操作按钮 + 消息       │
├─────────────────────────────────────────┤
│ 工具信息卡 (条件显示)                   │
├─────────────────────────────────────────┤
│ 可滚动列表                              │
│   行: [tag] [tag] [tag] 名称 版本 [按钮]│
├─────────────────────────────────────────┤
│ 分页: < Prev  1-50/205  Next >         │
└─────────────────────────────────────────┘
```

## 环境标签页

- **分类下拉**: Java | Python | Android | ... | Other (System) | Other (User)
- **工具信息卡**: 分类 ∈ {Java, Python, Android, Node.js, Go, Rust} 时显示
- **行格式**: `[名称] [来源徽章] [值] [Edit] [Del]`
- **添加对话框**: 名称 + 值 + 来源 (user/system)

## 包标签页

- **3 个独立筛选下拉**:
  - 功能: All | UI Framework | Web Framework | Data Science | Dev Tools | ...
  - 语言: All | Python | Node.js | Java | Rust | Go | C/C++ | Dotnet
  - 状态: All | Installed | Not Installed
- **行格式**: `[func_tag] [lang_tag] [install_tag] 名称 版本 [Add|Del]`
- **分页**: 50/页
